# Wi-Fi Campus Analyzer — Grupo 2

**Turma:** 3L6LASIR 1T  
**Tema:** A — Teste de Cobertura Wi-Fi  
**Linguagem:** Java

## Descrição
Aplicativo Android para pesquisar redes Wi-Fi próximas, filtrar pelo nome e apresentar SSID e intensidade do sinal (RSSI).

## Funcionalidades
- Pesquisa de redes Wi-Fi.
- Filtro por nome ou parte do nome.
- SSID e RSSI.
- Classificação do sinal.
- Duas Activities ligadas por Intent.

## Tecnologias
Android Studio, Java, ConstraintLayout, RecyclerView, WifiManager e BroadcastReceiver.

## Permissões
ACCESS_WIFI_STATE, CHANGE_WIFI_STATE, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION e NEARBY_WIFI_DEVICES.

## Execução
Abrir no Android Studio, sincronizar o Gradle, executar no dispositivo, ativar Wi-Fi/localização, escrever o nome da rede e clicar em **PESQUISAR WI-FI**.

## Testes do aplicativo
### 1. Tela inicial
Tela para escrever o nome da rede e iniciar a pesquisa.

### 2. Pesquisa
Pesquisa das redes Wi-Fi próximas.

### 3. Resultados
Lista das redes encontradas com a intensidade do sinal.
